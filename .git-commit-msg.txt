Добавить ETL реальных финансовых/налоговых данных ФНС (SQLite) и гейтинг demo-данных в risk-engine

ETL (npm run import:finance / import:fns-risk) импортирует официальные
открытые датасеты ФНС (доходы/расходы, налоговая задолженность,
дисквалифицированные лица, спецрежимы) в локальную SQLite через
встроенный node:sqlite — без внешних зависимостей. GIRBO/FNS-адаптеры
читают эти данные вместо демо-генератора, когда компания в датасете
найдена, с явными статусами partial/stale/demo.

Risk-engine теперь гейтит каждое правило по reliability источника —
demo-данные больше не участвуют в итоговом Risk Score ни при каких
условиях. Добавлена метрика покрытия (достоверность оценки в процентах)
с предупреждением при низком покрытии реальными данными.
