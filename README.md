# Контрагент

MVP сервиса проверки российских контрагентов. Пользователь вводит ИНН, ОГРН или название организации
и получает аналитическое досье с прозрачной оценкой риска (0–100), судами, исполнительными
производствами, банкротством, закупками и репутационным фоном.

> **Важно:** установочные данные компании (название, статус, адрес, руководитель, ОКВЭД, дата
> регистрации, признак недостоверности сведений) — **реальные данные ЕГРЮЛ** через бесплатный API
> [DaData](https://dadata.ru/api/find-party/), если задан `DADATA_API_KEY`. Остальные разделы
> (финансы, суды, ФССП, банкротство, закупки, репутация, учредители) — демонстрационные: у ГИР БО,
> КАД Арбитр, ФССП, ЕИС закупки и Федресурса нет простого бесплатного API, а полноценные аналоги
> (Контур.Фокус, Casebook, СПАРК-Интерфакс) — платные коммерческие подписки. Архитектура
> (`src/lib/providers`) позволяет подключить любой из них независимо от остальных, не трогая
> risk-engine и UI. Каждый раздел в интерфейсе явно помечен статусом источника (вкладка
> «Источники»), демо-данные никогда не выдаются за настоящие.

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · минимум зависимостей (jsPDF — единственная
дополнительная библиотека, нужна для генерации PDF).

## 1. Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) — сервис полностью работает без каких-либо
переменных окружения (используются демо-данные и шаблонное AI-заключение без обращения к ИИ).

Полезные команды:

```bash
npm run lint     # ESLint
npx tsc --noEmit # проверка типов
npm run build    # production-сборка
npm start        # запуск собранного приложения
```

## 2. Переменные окружения (опционально)

Скопируйте `.env.example` в `.env.local` и при желании укажите ключ Google Gemini:

```bash
cp .env.example .env.local
```

| Переменная       | Обязательна | Назначение                                                                 |
| ---------------- | ----------- | --------------------------------------------------------------------------- |
| `GEMINI_API_KEY` | Нет         | Ключ Google Gemini для AI-резюме досье. Без ключа используется шаблонное заключение (без ИИ) — сервис остаётся полностью рабочим. |
| `GEMINI_MODEL`   | Нет         | Название модели Gemini (по умолчанию экономичная `gemini-3.5-flash-lite`). |
| `DADATA_API_KEY` | Нет         | Ключ DaData для реальных данных ЕГРЮЛ (установочные данные компании). Без ключа — демонстрационные установочные данные, как и для остальных разделов. |

Ключ Gemini — [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey).
Ключ DaData — регистрация на [dadata.ru](https://dadata.ru/api/find-party/), бесплатный тариф до
10 000 запросов/день, ключ виден сразу в личном кабинете после подтверждения email.
Никогда не коммитьте `.env.local` в репозиторий — он уже в `.gitignore`.

## 3. Создание репозитория на GitHub

1. Зайдите на [github.com/new](https://github.com/new).
2. Название репозитория: `kontragent-mvp`. Не добавляйте README/`.gitignore`/лицензию — они уже есть в проекте.
3. Нажмите «Create repository».

## 4. Публикация проекта в GitHub

В корне проекта (`kontragent-mvp`):

```bash
git init
git add .
git commit -m "Initial commit: Контрагент MVP"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/kontragent-mvp.git
git push -u origin main
```

## 5. Подключение GitHub к Vercel

1. Зайдите на [vercel.com/new](https://vercel.com/new) и авторизуйтесь через GitHub.
2. Выберите репозиторий `kontragent-mvp` → «Import».
3. Vercel сам определит Next.js — framework preset менять не нужно.

## 6. Environment Variables в Vercel

На экране настройки импорта (или позже в Project → Settings → Environment Variables) добавьте:

- `GEMINI_API_KEY` — при наличии ключа (опционально)
- `GEMINI_MODEL` — например, `gemini-3.5-flash-lite` (опционально)
- `DADATA_API_KEY` — при наличии ключа, для реальных данных ЕГРЮЛ (опционально)

Без этих переменных сервис задеплоится и будет работать — просто AI-резюме будет шаблонным, а
установочные данные компании — демонстрационными.

## 7. Deploy

Нажмите «Deploy». Через 1–2 минуты Vercel выдаст рабочую ссылку вида
`https://kontragent-mvp.vercel.app`. При каждом новом push в `main` Vercel будет собирать и
выкатывать новую версию автоматически.

## Архитектура (кратко)

- `src/types/dossier.ts` — единый тип `CompanyDossier` и все связанные сущности.
- `src/lib/providers/*` — независимые адаптеры источников (ФНС, ГИР БО, КАД Арбитр, ФССП, ЕИС
  закупки, Федресурс, ЦБ РФ, веб-репутация). Каждый адаптер можно заменить на реальную интеграцию
  независимо от остальных — бизнес-логика ни к одному провайдеру не привязана напрямую.
  `fns.ts` — гибридный: при наличии `DADATA_API_KEY` берёт установочные данные из реального ЕГРЮЛ
  (`dadata.ts` — клиент DaData), иначе (и для учредителей/связанных организаций всегда) — из
  демо-генератора `mock-data/generator.ts`.
- `src/lib/risk-engine/*` — расчёт риска 0–100 обычным TypeScript-кодом (без ИИ), с полной
  трассировкой «почему получился такой балл» и отдельным модулем оценки риска сделки.
- `src/lib/ai/*` — абстракция `AIProvider`: `GeminiAIProvider` + `TemplateAIProvider` (fallback без
  ключа/при сбое). ИИ получает только уже посчитанные факты и рейтинг и не может их придумывать или
  менять.
- `src/lib/pdf/generateDossierPdf.ts` — серверная генерация PDF-досье (jsPDF + встроенный шрифт PT
  Sans с поддержкой кириллицы).
- `src/lib/repository/*` — абстракция хранилища; сегодня in-memory, позже подключается
  PostgreSQL/Supabase без изменений в остальном коде.
- `POST /api/check`, `POST /api/deal-risk`, `POST /api/pdf` — публичные API-эндпоинты.

Недоступность одного источника данных не ломает всю проверку — соответствующий раздел досье
помечается статусом источника (см. вкладку «Источники» на странице компании).
